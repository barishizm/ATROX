# ios/Widgets/

WidgetKit extension (`ATROXWidgets`): the workout Live Activity and Dynamic Island (P038).

- `Sources/` — the activity's views (Lock Screen, compact, minimal, expanded).
- `Resources/` — String Catalog of the extension (en + tr).
- `../Shared/` — `WorkoutActivityAttributes` and the App Intents (`SkipRestIntent`, `ExtendRestIntent`), compiled into
  both the app and the extension.
- Manual verification steps: `docs/TEST-NOTLARI.md`.
